📸 AI Face Attendance (AIFace) Production Architecture

An enterprise-grade, offline-first biometric facial recognition attendance system for Android & iOS built with Flutter, Google ML Kit, and TensorFlow Lite.

Star Repository

Sub-Second Biometric Matching

Processes raw camera buffers at 30+ FPS, crops aligned face bounding boxes, and performs cosine distance matching in ~70ms end-to-end.

100% On-Device Privacy

Zero cloud dependencies. Raw camera images are converted to transient mathematical vectors in memory and never written to disk.

Multi-Vector Liveness Shield

Continuously tracks eyelid coordinates (EAR) and light dispersion to defeat 2D paper printouts, tablet replays, and static masks.

1. Frame Ingestion & Normalization

Extracts YUV420/BGRA8888 plane buffers, handles hardware sensor rotation, and builds normalized RGB matrices.

2. 192-D Embedding Extraction

Feeds preprocessed 112x112 face crops into MobileFaceNet (TFLite) to produce L2-normalized 192-dimensional floating-point vectors.

3. Cosine Distance Verification

Compares live vector against enrolled staff using cosine distance: 1 - (A·B)/(||A||*||B||). Threshold < 0.85 = verified match.

Texture & Moire Analysis

Neural classifier evaluates high-frequency screen reflections and print moire patterns to reject presentation attacks.

Head Pose Bounds

Enforces physiological 3D Euler angles (pitch, roll, yaw) within natural human optical engagement thresholds.

Encrypted Local Cache

Embeddings and attendance records are stored locally with zero external network surface area, fully GDPR compliant.

Clean BLoC Pattern

Unidirectional data flow isolating hardware camera feeds, ML inference services, and presentation widgets into decoupled layers.

Throttled Stream Processing

Intelligent frame debouncing and state caching eliminate CPU/GPU thermal throttling during long kiosk operation.

Custom Canvas HUD

Hardware-accelerated CustomPainter renders dynamic Face ID ring viewfinders and bounding boxes across all screen aspect ratios.
